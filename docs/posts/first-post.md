# Создание простого блога для документации

Дата: 2024-01-10

## Задача

Создать максимально простой и бесплатный блог для размещения документации с минимальным функционалом:
- Добавление контента через Markdown-файлы
- Автоматическая публикация на хостинге
- Минимальная настройка и поддержка

## Реализация

### Выбранный стек

- **MkDocs Material** — генератор статических сайтов
- **GitHub Pages** — бесплатный хостинг
- **GitHub Actions** — автоматический деплой

### Структура проекта

```
mkdocs.yml              # Конфигурация
docs/
├── index.md            # Главная страница
├── about.md            # О блоге
└── posts/              # Заметки
    └── *.md
.github/workflows/      # CI/CD
    └── deploy.yml
```

### Как это работает

1. Markdown-файлы добавляются в `docs/posts/`
2. При пуше в main запускается GitHub Actions
3. MkDocs генерирует статический сайт
4. GitHub Pages публикует его

## Альтернативные варианты

### Jekyll + GitHub Pages

Плюсы:
- Интегрирован в GitHub Pages
- Меньше зависимостей

Минусы:
- Сложнее Ruby-экосистема
- Менее гибкая настройка для документации

### VitePress

Плюсы:
- Очень быстрый
- Красивый UI

Минусы:
- Требует Node.js
- Сложнее для новичков

### Docusaurus

Плюсы:
- От Facebook
- Мощная документация

Минусы:
- Требует React-знаний
- Избыточен для простого блога

## Вывод

MkDocs Material — оптимальный выбор для простого блога-документации:
- Одна команда для запуска
- Понятная структура
- Красивый дизайн из коробки
- Автоматический деплой

## Команды

Локальный запуск:
```bash
mkdocs serve
```

Деплой на GitHub Pages:
```bash
mkdocs gh-deploy
```
