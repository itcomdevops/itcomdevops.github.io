# Инструкция: Создание блога на MkDocs + GitHub Pages

Дата: 2024-01-10

## Задача

Создать максимально простой и бесплатный блог для документации с минимальным функционалом:
- Добавление контента через Markdown-файлы
- Автоматическая публикация на хостинге
- Минимальная настройка и поддержка

## Реализация

### Стек технологий

- **MkDocs Material** — генератор статических сайтов
- **GitHub Pages** — бесплатный хостинг
- **GitHub Actions** — автоматический деплой

### Структура проекта

```
mkdocs.yml                    # Конфигурация
docs/
├── index.md                  # Главная страница
├── about.md                  # О блоге
└── posts/                    # Статьи
    └── *.md                  # Markdown-файлы статей
.github/workflows/
└── deploy.yml                # CI/CD для автоматического деплоя
README.md                     # Описание проекта
.gitignore                    # Исключения для Git
```

### Пошаговая установка

#### 1. Создание репозитория на GitHub

1. Зайди на https://github.com/new
2. Repository name: `твой-никнейм.github.io`
3. Выбери **Public**
4. Нажми **Create repository**

#### 2. Установка MkDocs локально

```bash
pip install mkdocs-material --break-system-packages
```

#### 3. Создание файлов

Создай структуру файлов как описано выше.

#### 4. Настройка Git

```bash
cd /home/ubuntu/project/4
git init
git add .
git commit -m "initial commit"
```

#### 5. Создание токена GitHub

1. Зайди на https://github.com/settings/tokens
2. Нажми **Generate new token (classic)**
3. Note: "deploy"
4. Отметь **repo** и **workflow**
5. Нажми **Generate token**
6. Скопируй токен

#### 6. Первый деплой

```bash
git remote add origin https://твой-никнейм:ТОКЕН@github.com/твой-никнейм/твой-никнейм.github.io.git
git push -u origin main
```

#### 7. Настройка GitHub Pages

1. Репозиторий → **Settings** → **Pages**
2. Branch: **gh-pages**
3. Папка: **/(root)**
4. Нажми **Save**

Через 1-2 минуты сайт будет доступен по адресу:
**https://твой-никнейм.github.io**

## Как добавить новую статью

### Шаг 1: Создай Markdown-файл

Создай файл в папке `docs/posts/` с именем `название-статьи.md`

Имя файла должно быть на английском, через дефисы.

### Шаг 2: Напиши заголовок статьи

```markdown
# Заголовок статьи

Дата: 2024-01-10
```

### Шаг 3: Напиши контент

Пиши на Markdown — поддерживается всё:

```markdown
## Раздел

Текст параграфа.

- Список
- Второй пункт

### Подраздел

Код:

```bash
команда
```
```

### Шаг 4: Добавь ссылку на главную

Открой `docs/index.md` и добавь ссылку:

```markdown
## Последние записи

[Название статьи](posts/название-статьи.md)
```

### Шаг 5: Загрузи на GitHub

```bash
git add .
git commit -m "add: новая статья"
git push origin main
```

Сайт обновится автоматически через 1-2 минуты.

## Альтернативные варианты

### Jekyll + GitHub Pages

Плюсы:
- Интегрирован в GitHub Pages
- Меньше зависимостей

Минусы:
- Сложнее Ruby-экосистема
- Менее гибкая настройка для документации

### VitePress

Плюсы:
- Очень быстрый
- Красивый UI

Минусы:
- Требует Node.js
- Сложнее для новичков

### Docusaurus

Плюсы:
- От Facebook
- Мощная документация

Минусы:
- Требует React-знаний
- Избыточен для простого блога
